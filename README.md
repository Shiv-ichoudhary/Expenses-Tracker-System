# 💰 Expenses Tracker System

A simple, menu-driven command-line application built in Python that helps users record, organize, and monitor their daily expenses efficiently.

## ✨ Features
- **Add Expense:** daily spending with date, category, description, and amount.
- **View All Expenses:** Display a numbered list of all recorded expenses.
- **Calculate Total Spending:** Automatically calculate and view the total expenditure.
- **Interactive Menu:** Easy-to-use console interface.

## 🛠️ Technologies Used
- **Language:** Python 3

## 🚀 How to Run
1. Clone or download this repository.
2. Open a terminal in the project folder and run:
   ```bash
   python main.py
   ```
